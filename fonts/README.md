# Fonts

These are unmodified Latin WOFF2 files downloaded on 2026-09-28 from the
[Google Fonts stylesheet used by this site](https://fonts.googleapis.com/css2?family=Bricolage+Grotesque:opsz,wght@12..96,700;12..96,800&family=Lato:wght@400;700&display=swap).
The files are stored here so visitors do not connect to Google to load fonts.
Only the Latin subsets used by the English page are included. Other characters,
including emoji, use the system fallback fonts.
